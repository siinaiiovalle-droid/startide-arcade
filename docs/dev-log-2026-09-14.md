## 三、已知问题与风险（明日优先处理）

1. **数据只在本机**：账号、成绩、后台配置存 localStorage，换设备即丢失，无法跨用户排行。
   → 需引入后端 + 数据库（阶段二，见 `company-plan.md`）。
2. **后台口令是默认值且公网可访问**：建议第一时间改 `assets/js/auth.js` 中的 `ADMIN`，并增加二次校验。
3. **无中国大陆可用性保障**：`github.io` 在国内访问不稳定。
   → 阶段二需做 ICP 备案域名 + 国内 CDN / 或微信小游戏、抖音小游戏渠道。
4. **合规**：涉及中国大陆发行需版号、实名与未成年人保护；海外需隐私政策与 GDPR 合规（Cookie / 数据收集声明）。
5. **移动端手感**：已支持触屏，但虚拟摇杆 / 按键、横屏适配尚未做。
