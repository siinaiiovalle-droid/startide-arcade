## 四、遇到的问题

1. **海报精灵缺映射（提前修）**：`pipe`/`rhythm` 不在 `KIND_HINTS` 会落到通用手柄图标 → 在 `tools/poster_art.py` 新增 `pipe`（双色弯管 + 法兰）与 `music`（八分音符 + 分符）两个 sprite 分支，`nonogram` 归入 `block`。
2. **测试假故障两处（游戏无恙）**：① Node 侧 `hook()` 直接在 `page.evaluate` 里用（坑 26 重现）→ 改挂 `window.__H`；② 键盘方向键用瞬发 `press()` 被边沿检测整帧漏采（坑 6 重现，光标纹丝不动）→ 改 `down` → 260ms → `up`。
3. **pipe 手柄只有 A/B**：测试想用 dpad 导航发现 `data-k="right"` 按钮不存在（touchControls: ['a','b']）→ 改键盘导航到首个可旋转格再手柄 A 旋转断言。
4. **线上通道整体劣化**：curl 直连/代理全部 `000`（连一直正常的 `-4` 也不通），Chromium 首次 `ERR_CONNECTION_CLOSED`，30s 后重试浏览器通道恢复——今天线上验证全靠实页加载 + 页内 `__auto` 判定（页面能渲染、游戏能实例化本身就证明 JS 200）。
