## 遇到的问题与修复

1. **测试坑 27（新）**：`page.mouse.click` 按 `getBoundingClientRect` 换算点击**画布底部区域会静默失败**——画布高度 648px 的底部很可能在视口外，mouse.click 不滚动元素进入视口，点击无效且无报错（本次大富翁触屏掷骰按钮、猜数字数字键盘 0/✓ 键全部 miss 才暴露）。修复：统一改用 `page.locator('#stage canvas').click({ position: {x,y} })`（按 CSS 尺寸换算 + 自动滚动，兼顾坑 20）。
2. **测试坑 28（新）**：自动化驱动「双数再掷」类规则时，若注入骰子含 `d1===d2`（如 2=[1,1] 唯一拆分）会触发再掷 → 驱动器再次注入同样骰子 → **无限双数循环**（回合数卡死不前进，150s 超时）。修复：驱动器记录 lastDbl，双数后下一次强制 `[6,1]`，且目标搜索排除 dx=2。
3. **老虎机体验缺陷（真问题）**：筹码低于当前注额时 `doSpin` 直接拒绝（提示「调低押注」），筹码 50 注额 100 的玩家要自己摸索。修复：`doSpin` 自动降到可负担的最高档位再转；另加 idle 态破产兜底（`cash < 最低注` 直接结算），杜绝任何状态卡死。
4. 大富翁自动化策略两度翻车：先写反了收租方向（玩家踩对手地是**付租**不是收租，结果玩家输、best 不写入），再遇双数死循环。最终方案：`__auto.give(n)` 注资 + 玩家专注买地、电脑瞄准玩家地产送租，回合耗尽资产碾压获胜。
