## 遇到的问题与修复

1. **三款新游戏全部忘了注册 `env.loop`（真 bug，最大教训）**：engine 的 `frame()` 只调用 `loopCb`，没有 `env.loop(fn)` 注册则 update/render 永远不执行——画面全黑、pad 边沿全部失效、倒计时不走。因为 onKey 直触发与触屏直改状态**不经过 loop**，游戏呈现「触屏能点、键盘 Space 能按、方向键全死」的迷惑性半可用状态，非常难一眼定位。**修复后立刻：方向键移动 ✓、渲染 ✓、倒计时 ✓。** 对照检查：全部 36 款老游戏都有 `env.loop`，只有今日三款漏了。已把「create 末尾必须 `env.loop(update,render)`」加入自查清单首位。
2. **测试侧数学错误：对换序列重放还原必须逆序**。scramble 记录的是从恒等出发的对换轨迹 σ；从打乱态回到恒等要应用 σ⁻¹（**逆序**逐条对合），正序重放得到的是 σ²(恒等)≠恒等。首次重放后仅差一对（2↔7）正是 σ² 的效果。另加「归位排序」兜底（对任何中间态都收敛），消除测试前置操作（触屏 swap）对重放的污染。
3. **`page.waitForFunction` 在 playwright-cli run-code 环境不可靠**（reflex 首测 5 轮全抢跑、fouls=5 才发现）：改为页面内 `evaluate(() => new Promise(...))` 轮询（30ms 间隔）等状态机到位后立即触发，稳定复现。
4. **测试脚本闭包陷阱**：`page.evaluate(() => ... pickMid ...)` 引用 Node 侧变量会 ReferenceError，必须 `page.evaluate((pm) => ..., pickMid)` 传参。
