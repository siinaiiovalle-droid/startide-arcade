## 遇到的问题与修复

1. **赛车虚拟手柄切道无效（真 bug）**：切道只挂在 `onKey` 上，虚拟手柄设置的是 `pad.left/right`（不触发键盘事件）。修复：update 里补 `pad` 边沿检测（`prev.pl/pr` 去重）。**教训：凡是 onKey 里做的离散动作，必须同步检查 pad 边沿是否也接了**——这也是既有规约「一次性动作要补 onKey 直触发」的反向情形。
2. **直升机开局即坠**：reset 后立即以最大速度下坠，玩家约 0.8s 就撞地，来不及反应（自动化测试两次因此误判）。修复：开局 `vy=-60` 轻微浮力，留约 1.2-1.5s 反应窗口。
3. **测试误报两则**：直升机「按住」验证用 `click()`（瞬发 down+up）必然立刻松开 → 改 `mouse.down()` → 等 700ms → `mouse.up()`。
