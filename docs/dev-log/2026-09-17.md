## 四、踩坑记录

| 现象 | 原因 | 处理 |
|---|---|---|
| `mouse.click(x,y)` 报 `Invalid parameters` | 手算的页面坐标未保证落在画布可视区 | 改用 `locator('#stage canvas').click({ position })` 自动滚动与裁剪 |
| 点 `#btnRestart` 超时被拦截 | bubble 连发过程中已结算，`.modal` 遮住了按钮 | 先关闭弹窗；按钮点击统一改用 `evaluate(() => el.click())` |
| 改完 gem.js 后难度不生效 | 浏览器会话 HTTP 缓存未失效，`?cb=` 只能击穿 HTML、击穿不了 JS 子资源 | `playwright-cli close` 后重开会话复测通过。**改完静态资源复测必须先重开会话** |
| 泡泡龙「26 发 0 分」 | 全部垂直发射 + 颜色随机，且很快爆线，之后按键被 `over` 忽略 | 改为 ±1.2rad 变角度扫描，第 2 发即命中。属测试脚本问题，非游戏缺陷 |
