## 四、遇到的问题

1. **push 报 403 `denied to huangwei361`**：Windows 凭据管理器里的旧账号凭据抢在了 `.git-credentials` 的 `siinaiiovalle-droid` 之前。按文档改用 token 直连（`git -c credential.helper= ... push https://<owner>:<token>@github.com/...`）并短 `-c http.proxy= -c https.proxy=` 绕过代理，一次成功。后续如遇 403 直接走这条。
2. **线上验证全线 404 / `ERR_CONNECTION_CLOSED`**：该域名 DNS 只返回 IPv6，本机 IPv6 链路抖动，`curl` 与 Chromium 默认都走 IPv6 → 时好时坏；加 `curl -4` 稳定 200，Chromium 侧重试后可通。另发现带 `?cb=` 随机 query 的 URL 会被中间缓存判 404，线上冒烟脚本已去掉 query。
3. **海报主视觉空白（真 bug，已修）**：`tools/poster_art.py` 的 `bubble` 分支坐标写错——元组里的 `cx-16` 已是像素值却又乘了一次 `u`，导致圆心 y≈358 落到 280 画布之外，泡泡整个画飞。改为与其他分支一致的 `cx - 16 * u`，并去掉绘制时的二次乘 `u`。同时给 `KIND_HINTS` 补映射：`maze → block`、`bullet → bubble`，避免新 id 落到通用手柄图标。
4. **三处测试假故障（游戏本身没问题）**：① 迷宫起点右侧/下方本就是墙，硬断言 `move('right')` 必动会误报 → 改读 `__auto.open()` 选一条真通路；② 点格寻路的走廊在完美迷宫里可能绕很远，固定 1.8s 等待没走完 → 改轮询等到达（实测 9s 内到达 (2,0)）；③ 早期版本里 `A()` 是 Node 侧函数却在 `page.evaluate` 里调用（坑 26）→ 改挂 `window.__A`。
