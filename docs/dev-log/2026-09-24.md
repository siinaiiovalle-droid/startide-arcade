## 遇到的问题与修复（今日全是「输入通路」问题）

1. **射箭箭矢穿透靶子**：落地判定只有飞出画布一种，箭会视觉上穿过靶心且 forceLand 后继续飞走判脱靶。修复：箭与靶心距离 <60px 即插靶结算。
2. **进阶鸟键盘无法开局（真 bug）**：`update` 中 `if (!started) return;` 挡在 pad.a 边沿检测之前，扑翼输入永远走不到（只有 pointerdown 能开局）。修复：输入检测移到 started 守卫之前。
3. **守塔虚拟手柄全面失灵（真 bug，racer 同类问题的再现）**：选格 `moveSel` 与建造都只挂在 onKey/pointerdown，pad 四方向与 A 键边沿全部没接——手柄只能看不能玩。修复：update 补 pad 四方向 + A 边沿。**连续两天（racer、towerdef）栽在同一坑，规约升级为硬性自查项：新游戏的每个离散动作必须同时具备 onKey 与 pad 边沿两条通路，写完先跑一遍手柄脚本再提测。**
4. **测试侧**：进阶鸟自动驶验用 `list()` 钩子读最近管道缺口做简单寻路（对准缺口中心扑翼），实测飞到 28 分，验证金币与漂移管道；守塔漏怪验证需要耐心（一格 60px 全程约 32s，分段轮询等待）。
