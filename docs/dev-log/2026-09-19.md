## 三、遇到的问题

1. **BFS 求解器两版踩坑**：第一版按棋子 id 区分状态，状态空间 6.6 万+ 仍找不到目标（等效棋子交换导致同形异名状态爆炸）；改为**按形状归一**（cao/v/h/s 四类）后空间缩到 2.6 万，毫秒级出解。重放时因同形棋子可互换，需维护「形状前缀 id → 真实棋子」映射 + 同形兜底重试。
2. **每帧抛错三连**：三款游戏都中了「`prev` 未初始化」坑（每帧 `prev[k] = ...` 抛 TypeError，引擎捕获后 render 不执行、画面静止）；link/sudoku 的 render 还引用了未声明的 `i`/`f`。修复：`reset()` 里 `prev = {}`，render 顶部 `var i, f;`。
3. **连线 BFS 越界**：搜索走廊延伸到棋盘外（r=-1 行）时 `grid[qr]` 为 undefined 抛错。修复：越界格视为通道，仅在棋盘内才查 `grid`。
4. **数独「同数=擦除」**：填数时再按同数字会擦除（这是设计行为），但测试全盘填充时对已填对格子重复 set 会把它擦掉导致永远差一格不通关。测试改为「先擦再填」。
5. **测试进程被跑崩**：逐条 RPC 重放 27 步 + 每步 120ms 等待时 playwright 会话被杀。改为单次 `evaluate` 批量重放后恢复。
6. **推送 TLS 抖动**：`git push` 连续报 `TLS connect error: unexpected eof`（代理不稳），本地提交 `9cb6282` 待网络恢复后重推；`git ls-remote` 同样报错确认是网络问题非权限问题。
