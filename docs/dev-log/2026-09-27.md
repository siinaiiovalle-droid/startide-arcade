## 遇到的问题与修复

1. **虚拟手柄按钮由 `touchControls` 决定**：三款初版照抄 `'a','b'`，手柄渲染不出方向键（`data-k=left` 查无此元素）。修正：pong `['left','right']`、sumo `['up','down','left','right','a']`、fifteen `['up','down','left','right']`。
2. **sumo 冲刺「假故障」排查（教训：先怀疑测试时序再怀疑代码）**：两次实测冲刺均无效，一度怀疑 Space→pad.a 映射。加 pad/dashT 状态钩子逐帧观察后真相是两件事叠加：① playwright 通路其实一直正常（stam 100→71.8），`stam=100` 是**冲刺把 AI 撞飞出界触发 roundEnd 复位**——冲刺物理有效性的旁证；② 手柄 A 失败是上一场 roundEnd 的 **1.2s 暂停窗口吃掉了瞬发 mousedown**（update 提前 return 不检测边沿）。顺带修掉一个真手感问题：**冲刺 0.42s×740=310px 几乎必把自己冲出界自杀**，缩短到 0.28s（207px）。测试断言改用 `dashT>0` 直读并轮询等 `phase==='play'` 避开暂停窗口。
3. **pong 驱动器竞速 bug**：只监听己方得分变化来重置注入标志，AI 得分后不再注入 → AI 连刷到 7:1。修复：监听双方比分变化 + 每次注入前 `setPad` 归位；注入点从 (44,350)（AI 0.65s 内可达）改为右上死角 (530, 720px/s) 双保险。
4. **fifteen 一次按键滑 3 步**：onKey 直触发 + pad 边沿 + 按住重复三路叠加。修复：`slideDir` 统一 120ms 全局节流（slideAt 点击路径不节流）。
5. **fifteen 逆序重放被测试前置滑动污染**：重放前先点 `#btnRestart` 重新打乱再逆序重放，15/15 全归位（延续坑 24 的逆序公式：第 k 步逆放 = `slide(moves[k].e)`）。
6. **sumo 触屏摇杆被手柄 DOM 截获 pointerdown**（五键布局覆盖画布中央，这也解释了昨日坑 27 的另一半成因）：测试改用页面内合成 `PointerEvent` 直发 canvas。
