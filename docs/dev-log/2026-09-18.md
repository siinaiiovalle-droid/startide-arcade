## 四、遇到的问题

1. **切水果一度「切不到水果」**：初版发射初速 `vy = -880` 配重力 1250，水果只在屏幕底部约 220px 内活动，测试划动区（上部）自然切不到，键盘纵斩也常空。改为 `vy ∈ [-1240,-1080]`、重力 1180、半径 30–42，水果顶点抬到约 y=200，整个画面都成为有效切割区。
2. **测试脚本把结算弹窗点掉了**：挂机等待弹窗期间脚本仍在划屏，鼠标按到弹窗遮罩导致弹窗被关、`gameOverModal` 误报 false。修法：滑动循环条件里加 `!(await modalUp())`，弹窗一出立刻停手。
3. **瞬发按键会被漏采**：`page.keyboard.press('ArrowLeft')` 的 down/up 几乎同帧，持续型输入（贪吃蛇转向、2048 滑动）可能一帧都采不到，误判成"游戏冻结"。必须用 `keyboard.down()` → 等 700ms → `keyboard.up()`。
4. **跑酷分数天然不为 0**：恐龙跑酷按距离自动积分，重开后立刻就 > 0，「重开后分数归零」这条判定不适用，改为"回到低位（< 40）"。
5. 静态服务中途被清理进程杀掉导致 `ERR_CONNECTION_REFUSED`，重启服务即恢复（不是代码问题）。
