## 三、遇到的问题

1. **方向键被处理两次**：`engine` 已把方向键 / WASD / Space 映射进 `pad`，若游戏再在 `onKey` 里处理一次会导致光标一次移动两格。解决办法：`onKey` 只处理 `Enter / NumpadEnter`，方向与确认统一走 `pad` 边沿检测（`prev` 记录上一帧状态）。三款新游戏均按此实现。
2. **既存 bug：`UI.initNav is not a function`**（`assets/js/layout.js:158`）。`UI` 未导出 `initNav`，但导航高亮已由 `renderNav` 按 `data-page` 处理，故改为防御性调用 `if (global.UI && global.UI.initNav)`，全站页面消除该报错。
3. **既存 bug：打砖块无法启动**（`assets/js/games/breakout.js` 使用 Node 风格 `global.addEventListener`）。浏览器无 `global`，`create()` 直接抛错，画面全空。已改为 `window.addEventListener / removeEventListener`，修复后正常渲染运行。
4. **既存体验问题：贪吃蛇开局约 1.6 秒撞右墙**。蛇默认向右、0.16s/格，玩家来不及反应。新增待机态 `armed`：首次方向输入（键盘或触屏滑动）前不推进，并绘制「准备出发」提示。
5. **测试踩坑**：Python `http.server` 无 `Cache-Control`，Chromium 会缓存旧 JS，导致修复后仍读到旧文件、误判为「未修复」。解决办法是换新端口重新打开页面（换 origin 即绕开缓存）；PowerShell 直接传 JS 给 CLI 会吞掉双引号，改用 base64 传参。
