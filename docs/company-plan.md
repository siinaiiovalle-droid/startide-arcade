## 一、我们是谁、要做什么

**定位**：面向全球（含中国大陆）的**网页/小游戏研发与运营公司**。

**产品形态**：免安装、即点即玩的网页小游戏平台 —— 打开浏览器就能玩，手机、平板、电脑、智能电视全端覆盖。

**一句话战略**：用**高频、低成本的小游戏供给**换**流量规模**，用**数据与运营**把流量沉淀为**长期用户资产**，最终升级为「引擎 + 平台」的复合体。

**为什么是网页游戏**：
- 零安装门槛，分享即转化，获客成本远低于 App；
- 一套代码多端运行，研发与维护成本最低；
- 经典玩法（休闲、益智、街机复刻）生命周期极长，可长期吃流量长尾；
- 天然适合 SEO 与社媒传播，是海外低成本获客的最优解。

## 三、四阶段路线图

### 阶段一：产品供给爬坡（2026-09-15 → 2026-10-15）· 进行中

**核心任务：把游戏数量堆起来，把站点跑稳。**

- 每天新增 **2–3 款**小游戏并推送上线（`game-pipeline.md`）
- 一个月内累计 **30+ 款**，覆盖街机、益智、棋牌、休闲四大品类
- 大厅能力补齐：分类筛选、搜索、热门 / 最新 / 收藏、最近在玩
- 移动端专项适配：竖屏布局、虚拟按键 / 手势、性能降级策略
- 双语（中 / 英）覆盖到全部游戏名称与说明
- 每款游戏接入：音效、暂停、结算、全球本地排行榜
- 每日工作日志 + 线上冒烟制度化

**完成标志**：30 款游戏稳定在线，移动端可完整游玩，日均无崩溃。

---

### 阶段二：数据与账号后端化（2026-10 → 2026-12）

**核心任务：把「本机数据」变成「真实用户资产」。**

- 引入后端服务 + 数据库：账号、成绩、排行榜、存档跨设备同步
- 账号体系升级：邮箱 / 手机号验证、第三方登录、找回密码、防刷
- 后台管理平台升级为真实数据源：实时 DAU、留存漏斗、分游戏数据看板
- 埋点体系：启动、时长、关卡流失、分享点击、广告曝光
- 中国大陆可用方案：独立域名 + ICP 备案 + 国内 CDN；同步筹备微信 / 抖音小游戏版本
- 合规：隐私政策、未成年人保护、实名与防沉迷（国内）、GDPR（海外）

**完成标志**：真实注册用户 20 万，跨设备数据互通，后台看的是真实数据而非演示数据。

---

### 阶段三：发行、增长与变现（2027-01 → 2027-09）

**核心任务：用流量和变现证明商业闭环。**

- 增长链路：海外 SEO（每款游戏独立落地页）、Reddit / X / TikTok 内容分发、itch.io 与游戏聚合站投稿、KOL 试玩
- 国内链路：微信 / 抖音 / QQ 小游戏平台、4399 / 7k7k 等渠道联运
- 变现结构：
  - 激励视频（复活、道具、双倍积分）—— 主力
  - 插屏 / Banner —— 补充
  - 会员去广告 + 专属皮肤
  - 品牌定制小游戏（To B）
- 运营节奏：每周新游、每月主题活动、赛季排行榜、成就与分享裂变
- 团队扩充至 30 人左右，形成「引擎组 / 游戏组 / 增长组 / 平台组」

**完成标志**：月流水 ¥500 万，DAU 50 万，单一渠道依赖度低于 40%。

---

### 阶段四：平台化与资本化（2027-10 → 2028）

**核心任务：从做游戏，变成做「做游戏的基础设施」。**

- 自研引擎 StarCore 与可视化编辑器对外开放，向中小团队授权
- 游戏 SDK 化：账号、支付、广告、数据一套接入
- 多语言与多区域发行（英 / 西 / 葡 / 日 / 韩 / 阿拉伯语）
- 引入战略融资，或由产业链上下游并购

**完成标志**：平台外部开发者 100+，非自有游戏贡献 20% 流量。

## 四、商业模式

| 收入来源 | 说明 | 目标占比 |
|---|---|---|
| 广告变现 | 激励视频为主，插屏与 Banner 为辅 | 55% |
| 会员订阅 | 去广告 + 专属皮肤 + 云存档 | 20% |
| 道具内购 | 复活、提示、皮肤、赛季通行证 | 15% |
| To B 定制 | 品牌营销小游戏、渠道联运分成 | 10% |

**成本结构**：研发人力 30%、发行买量 34%、美术与音效外包 12%、服务器带宽 8%、运营客服 9%、职能合规 7%。

## 六、当前约束（必须正视）

1. **数据是本地的**：现阶段 localStorage 存储，无跨设备、无真实排行 → 阶段二解决。
2. **`github.io` 国内访问不稳定** → 阶段二用备案域名 + CDN 解决。
3. **合规风险**：国内发行需版号、实名、防沉迷；海外需隐私与 GDPR 合规。
4. **内容版权**：经典玩法可复刻，**美术与音乐素材必须原创或已授权**，不得直接搬运 IP（超级玛丽等需做成「致敬玩法 + 原创美术」）。
5. **默认后台口令 `admin / admin888` 已暴露在公网**，须立即修改。
